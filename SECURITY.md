# Política de Segurança

Caso encontre alguma vulnerabilidade, por favor não abra uma Issue pública.

Entre em contato diretamente com o mantenedor do projeto.

## Versões suportadas

| Versão | Suporte |
| ------ | ------- |
| 1.x    | ✅       |
| 0.x    | ❌       |

## Divulgação responsável

Após a confirmação da vulnerabilidade será publicada uma correção em uma nova versão do projeto.
